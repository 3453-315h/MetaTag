## 2024-05-24 - PySide6 Slider Accessibility & Buddy Associations
**Learning:** Standard UI elements like `QSlider` in PySide6 default to having an empty `accessibleName`, which causes issues for screen readers. Furthermore, adding layout widgets via inline, anonymous `QLabel` declarations (e.g., `layout.addWidget(QLabel("Vol:"))`) prevents you from assigning a keyboard accelerator or setting a buddy relationship (using `.setBuddy()`) to associate the label with its input control.
**Action:** When creating slider controls or inputs, explicitly set their `.setAccessibleName()`. Always instantiate labels as variables (`self._my_label = QLabel("&Label:")`) so that you can assign an ampersand (`&`) for a keyboard accelerator and use `.setBuddy(target_widget)` to establish a programmatic link between the label and the control.
